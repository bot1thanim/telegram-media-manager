# ארכיטקטורת סנכרון נושאים ומדיה

## מטרה

המערכת מסנכרנת מדיה מקבוצת מקור בעלת נושאי Forum אל קטגוריות פנימיות, ולאחר מכן מפרסמת את המדיה לכל נושא תואם בקבוצת יעד. כל פעולה מתועדת בדוח בר־ביקורת הכולל הצלחות, כישלונות, נושאים שנוצרו, כפילויות ופריטים שדולגו.

## גבולות Telegram והפתרון

Telegram Bot API מקבל עדכונים חדשים בלבד ואינו מספק לבוט שיטה לקרוא את ההיסטוריה הקיימת של קבוצה. קריאת היסטוריה זמינה ב־Telegram User API בלבד. לכן הפתרון מורכב משני חלקים: כלי ייבוא חד־פעמי, המופעל מקומית ובאישור בעל החשבון באמצעות Telethon, וסנכרון חי מתמשך של הודעות ונושאים חדשים דרך ה־webhook של הבוט.

כלי הייבוא ההיסטורי קורא את קטלוג הנושאים של קבוצת המקור ושל קבוצת היעד, מייבא את רשומות המדיה מקבוצת המקור ושומר את מזהי קבוצת המקור, ההודעה והנושא. הוא אינו שומר מספר טלפון, קוד אימות, סיסמה או session string במסד הנתונים או בקובץ שנמצא ב־Git. קובץ ה־session נשמר מקומית בלבד ומוחרג מגרסת המקור.

## תצורה

| משתנה | משמעות | תאימות לאחור |
|---|---|---|
| `SOURCE_GROUP_CHAT_ID` | מזהה קבוצת ה־Forum שממנה נאספים נושאים ומדיה. | אם חסר, נעשה שימוש ב־`GROUP_CHAT_ID`. |
| `TARGET_GROUP_CHAT_ID` | מזהה קבוצת ה־Forum שאליה מתפרסמת המדיה. | אם חסר, נעשה שימוש ב־`GROUP_CHAT_ID`. |
| `GROUP_CHAT_ID` | מזהה הקבוצה בפריסה הישנה. | נשאר נתמך ולא יוסר. |
| `TELEGRAM_API_ID` | מזהה אפליקציית Telegram User API עבור הייבוא המקומי בלבד. | לא נדרש לשרת Render או לסנכרון החי. |
| `TELEGRAM_API_HASH` | סוד אפליקציית Telegram User API עבור הייבוא המקומי בלבד. | לא נדרש לשרת Render או לסנכרון החי. |
| `TELEGRAM_IMPORT_SESSION_PATH` | נתיב מקומי אופציונלי לקובץ session של Telethon. | ברירת המחדל היא קובץ מקומי שאינו ב־Git. |

## קטלוג נתונים

לכל נושא שנראה בקבוצת המקור או בקבוצת היעד נשמרים `chat_id`, `thread_id`, שם התצוגה והשם המנורמל. קטגוריה פנימית מקושרת לנושא המקור שלה דרך `source_group_id` ו־`source_thread_id`, ולנושא היעד דרך `target_group_id` ו־`telegram_thread_id`.

לכל פריט מדיה נשמרים מזהה קבוצת המקור, מזהה ההודעה ומזהה הנושא. האילוץ הייחודי על צמד קבוצת המקור והודעה מונע ייבוא חוזר של אותה הודעה. זיהוי הקובץ הייחודי הקיים נשאר שכבת הגנה נוספת מפני כפילויות תוכן.

## כללי התאמת שמות

ההתאמה היא דטרמיניסטית, ניתנת להסבר ואינה תלויה במודל שפה. היא שומרת על פרטיות ומונעת התאמה שרירותית.

| שלב | פעולה | תוצאה |
|---|---|---|
| 1 | נרמול Unicode, הסרת ניקוד עברי, קיפול רישיות, איחוד רווחים והסרת סימני פיסוק ועיטור. | `סדרות  - טורקיות` ו־`סדרות טורקיות` זהים. |
| 2 | נרמול צורות סופיות והסרת ה״א הידיעה בתחילת מילה. | וריאציות אורתוגרפיות נפוצות מתאחדות. |
| 3 | יצירת וריאציות יחיד/רבים בעברית ובאנגלית. | `ישראלי` ו־`ישראליות`, או `movie` ו־`movies`, מקבלים ציון התאמה גבוה. |
| 4 | השוואה מדויקת של השם המנורמל והווריאציות. | התאמה אוטומטית ובטוחה. |
| 5 | השוואה מטושטשת רק מעל סף שמרני ועם פער מספק מהמועמד השני. | מונעת פרסום לנושא שגוי כאשר ההתאמה עמומה. |

התאמה עמומה אינה מפורסמת אוטומטית. אם אין התאמה בטוחה, השירות יוצר נושא חדש בקבוצת היעד בשם הקטגוריה, בתנאי שלבוט יש הרשאת ניהול נושאים. אם יצירת הנושא נכשלת, הקטגוריה וכל המדיה שלה ייכללו בדוח החריגים ללא שליחה.

## פרסום, כפילויות והתאוששות

לפני פרסום רוחבי, השירות רוכש נעילה טרנזקציונית זהה לזו של עבודות הפרסום הקיימות. הוא יוצר תור עמיד, מקצה כל קטגוריה לנושא היעד שלה ומפעיל worker טורי עם טיפול ב־FloodWait. כל פריט מסומן `SENDING` בטרנזקציה לפני הקריאה ל־Telegram. במקרה של אתחול בזמן שהתוצאה אינה ידועה, הפריט מסומן ככישלון ולא נשלח מחדש אוטומטית, כדי למנוע פרסום כפול.

פריטים שכבר פורסמו אינם מוכנסים לתור חדש. פריטי מקור זהים מדווחים ככפילויות ומדולגים במהלך הייבוא. לאחר סיום ה־worker, נוצר דוח שמור הכולל מספר קטגוריות, נושאים שהותאמו, נושאים שנוצרו, הודעות שנשלחו, כפילויות, פריטים שדולגו, כשלים מפורטים וחיווי על מדיה שבורה.

## הרשאות

ייבוא היסטורי והפעלת סנכרון נושאים זמינים ל־Owner בלבד. הפצת "שלח לכל הקטגוריות" זמינה ל־Owner ול־Admin בעלי הרשאת `PUBLISH`. Viewer אינו יכול להתחיל ייבוא או פרסום. כל פעולה נרשמת ביומן הביקורת הקיים.

## דרישות הרשאה ב־Telegram

הבוט חייב להיות חבר בשתי הקבוצות. בקבוצת היעד הוא חייב להיות מנהל בעל הרשאת `can_manage_topics` כדי ליצור נושאים חסרים, ובהרשאות המתאימות לשליחת מדיה. כדי לקלוט הודעות חדשות מקבוצת המקור יש לנטרל את Privacy Mode של הבוט דרך BotFather, או להשתמש בהרשאות שמאפשרות לבוט לקבל את ההודעות הדרושות.
